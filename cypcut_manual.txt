# ファイバーレーザー加工機（3kW）取扱説明書 CYPCUT E 操作ガイド

---

## 1. 安全上の重要な注意事項

### 一般的な安全事項

* 本機の操作は、本書を完全に理解し、適切な訓練を受けた者のみが行うこと。


* 操作中は必ず適切な保護具（レーザー保護メガネ、防塵マスクなど）を着用すること。


* 加工中は加工エリアに不必要な人員を近づけないこと。


* 緊急時には直ちに緊急停止ボタンを押して機械を停止させること。


* 設置場所は十分な換気が確保され、可燃物から離れていることを確認すること。


* 定期的にメンテナンスを行い、異常がないことを確認すること。


* **[PLC] は変更しないこと**。



### レーザーに関する安全事項

* レーザー光を直接目で見ないこと（失明の原因となる）。


* レーザー光が皮膚に当たらないようにすること（火傷の原因となる）。


* レーザー光路の周辺には反射性の高い物を置かないこと（意図しない方向への反射による危険防止）。


* 加工中に発生するヒュームやガスを適切に排気すること。


* 切断機底面に切り屑受けが確実に設置されているか確認すること（切り屑受けがない場合、床面にレーザーが到達し火災の危険がある）。



### 電気に関する安全事項

* 濡れた手で電気部品に触れないこと（感電の原因となる）。


* 異常な発熱・異音・異臭が発生した場合は直ちに電源を切り、販売店または専門業者に連絡すること。

* 保護レンズ（定期交換品）

* 冷却水（規定品を使用）


* 潤滑油（ガイドレール用）



### 設置要件

* **設置場所の選定:** 十分な耐荷重のある水平な床面、振動が少ない場所、直射日光・高温多湿を避けた温度変化の少ない場所、十分な作業・メンテナンススペース、適切な換気設備の設置。


* **電源接続:** 三相AC380V（変圧器200V→380V使用）。必ずアース（接地）を接続。


* **冷却装置接続:** 指定の冷却水を使用。チラー水温を規定値内（20℃以上32℃未満）に保持。


* **ガス供給接続:** 切断ガス（酸素・窒素・圧縮空気など）を接続。ガス圧力が1.5MPa以上であることを確認。


* **排気ダクト接続:** ヒューム・粉じん排気用のダクトを確実に接続。

## 3. 起動と停止手順

### 起動手順

1. **動作範囲確認:** ヘッド稼働エリアに障害物がないことを確認（原点復帰時に左下へ移動するため）。


2. **本体起動（盤面操作）:**
* 主電源ブレーカーを **ON** にする。


* 制御盤の **①メインキー** を回す。


* **②メインスイッチ（緑ボタン）** を押す。


* **③発振器電源キー** を回す。


* システム（PC）が完全に立ち上がるまで待機。


* *(※④緊急停止スイッチは通常操作では触れない)*




3. **CypCutEの起動:** デスクトップの「CypCutE」アイコンを起動し、警告画面で「OK」をクリック。


4. **機械原点復帰（必須）:** 画面左下の「原点（ホームマーク）」をクリックし、確認画面で「OK」をクリック。ヘッドが左下に移動して原点確認を完了（ソフト起動時は省略不可）。



### 停止手順

1. CypCutE アプリケーションを終了。


2. OS（PC）のシャットダウン処理を実行。


3. システムの完全停止を確認後、制御盤の発振器キー、メイン電源キーを OFF にする。


4. 主電源ブレーカーを OFF にする。

## 5. 基本加工フロー・ファイル読込・レイヤー設定

### 加工の流れ

1. **ファイルを開く:** DXF形式を推奨。文字は必ずCAD側でアウトライン化しておく。


2. **レイヤー設定:** 材質・板厚に応じた切断条件を設定。


3. **マイクロジョイント設定:** φ20mm以上の打ち抜き形状には設定推奨。


4. **ブリッジ / 分解（必要時）:** 文字など中心が孤立する形状に橋渡しを設定。


5. **加工順序（並び替え）:** 原則「内側 → 外側」順でソート。


6. **シミュレート / フレーム確認:** 加工前に動作範囲と軌跡を確認。


7. **加工実行:** シャッター（待機） → スタートの順で切断開始。



### ファイルを開く操作

* **対応形式:** DXF（最も安定・推奨）、AI（DXF変換推奨）、PLT、Gerber、LXD、Gコード。


* **操作手順:**
1. 画面左上「ファイル（File）」をクリック。


2. プレビューで確認し、読み込むファイルをダブルクリック。


3. インポート設定（単位・スケール）を確認して「OK」をクリック。




* ※既存図形を保持したまま追加する場合は「ファイル → インポート」を使用。


* ※「ファイル → 履歴ファイル」からサムネイル一覧でアクセス可能。





### レイヤー設定（切断条件）

図形ごとに切断条件（出力・速度・ガスなど）をグループ分けする機能。

* **図形へのレイヤー割り当て手順:**
1. 選択ツール（矢印）で対象図形を選択。


2. 右側のレイヤーカラーパネルから目的のレイヤーをクリック（色が変化）。




* **レイヤーパラメーターの設定:**
* 右ツールバーの「レイヤー（Layer）」をダブルクリック、または `F2` キーを押下。





#### レイヤー設定パラメーター表

| パラメーター | 説明 | 目安 |
| --- | --- | --- |
| 切断速度 | 目標切断速度（コーナー部は自動減速）。

 | 材質・板厚により異なる

 |
| ノズル高さ | ノズルと板材間の追従距離。

 | 通常 0.5〜1.5mm

 |
| ガス種 | 補助ガスの種類（O2 / N2 / Air）。

 | 鉄: O2、SUS/Al: N2 または Air

 |
| ガス圧力 | 切断時の補助ガス圧力。

 | 1.5MPa以上を確認

 |
| ピーク出力（%） | レーザーのピーク出力（3kW機: 100% = 3000W）。

 | 材質・板厚により調整

 |
| デューティサイクル（%） | PWM信号のデューティ比。

 | 切断条件に合わせて設定

 |
| パルス周波数（Hz） | 1秒間のレーザー発振回数。

 | 切断条件に合わせて設定

 |
| フォーカス位置 | ノズル先端からフォーカス（焦点）までの距離。

 | レンズ仕様に合わせて設定

 |
| レーザーON遅延 | ピアスを確実に行うための照射持続時間（ms）。

 | ms単位で設定

 |

## 6. 図面編集・加工パス機能詳細

### マイクロジョイント（Micro Joint）

切断時にレーザーを一瞬止め、パーツの板材からの脱落や跳ね上がりによるヘッド衝突を防ぐ。

#### 板厚別設定目安表

| 板厚目安 | ジョイント長さ | 個数目安 | 備考 |
| --- | --- | --- | --- |
| 〜 1mm | 0.3〜0.5mm | 2〜3個 | 薄板は長めに設定

 |
| 2mm | 0.2mm | 3個 | 参考標準値

 |
| 3〜5mm | 0.2〜0.3mm | 3〜4個 | 形状サイズに応じて増やす

 |
| 6mm以上 | 0.3〜0.5mm | 4個以上 | 重量があるため個数を増やす

 |

* **自動設定:** 図形選択 →「マイクロジョイント」→「自動マイクロジョイント」→ 個数・長さを入力し「OK」。


* **手動追加:**「マイクロジョイント」を有効化後、図形上の任意位置をクリック（`ESC` で終了）。


* **削除:** 個別は `Shift` + クリック。一括は「クリア」→「マイクロジョイントをクリア」。


* ※レイヤー設定の「マイクロジョイントでフライカット」を有効化すると、ジョイント部で減速停止せず高速通過可能（ピアスOFF時のみ）。



### 分解（Explode）とブリッジ（Bridge）

* **分解:** グループ化されたCADデータや文字列を単一パスに分離。


* 手順: 図形選択 →「グループ」→「分解（Explode）」。




* **ブリッジ:** 「O」「D」など中抜き文字の中心脱落を防ぐため、輪郭同士を繋ぐ橋を生成。


* 手順: 先に文字を「分解」→「ブリッジ」を選択して幅を設定（例: 2mm）→ 橋渡ししたい箇所をまたぐように線を引く。





### リード線（Lead Line）

ピアスのスパッタ痕を切断面に残さないための進入・脱出パス。

#### リード線パラメーター表

| パラメーター | 説明 | 目安・推奨値 |
| --- | --- | --- |
| タイプ（Type） | 直線（Line） / 円弧（Arc） / 直線+円弧

 | 板厚3mm以上は円弧を推奨

 |
| 角度（Angle） | 切断ラインへの進入角度

 | 30°〜90°（一般的に45°）

 |
| 長さ（Length） | リードインの助走距離

 | 板厚の2〜5倍を目安に設定

 |
| 半径（Radius） | 円弧タイプのみ有効な進入半径

 | 1〜3mm

 |
| 穴付きリードイン | リードイン開始点に小さな穴を追加

 | 厚板のピアス安定性向上に有効

 |
| リード終点（Lead Out） | リードアウトの形状・角度・長さ

 | 不要な場合は「None」（シールで代用）

 |
| リード終点レーザーオフ | リードアウト移動中にレーザーを切る

 | 終端の焼け防止時にON

 |
| リード位置 | リードを配置する辺の優先度（長辺から入る等）

 | 通常はデフォルト

 |
| 閉じた図形のみ | 閉じた輪郭にのみリード線を生成

 | 通常はON

 |
| リード線の確認 | 他図形との干渉を自動チェックし短縮

 | **常にONを推奨**

 |

#### 密着・隙間・オーバーカット・マルチ切断（「密着」ドロップダウン）

| 機能 | 説明 | 用途 |
| --- | --- | --- |
| **密着（Seal）** | 始点と終点をわずかに重ねる

 | 切り残しの防止（最も一般的）

 |
| **隙間（Gap）** | 終点を始点手前で止める

 | マイクロジョイント併用の脱落防止

 |
| **オーバーカット（Over）** | 終点を始点より少し先まで切断

 | 確実に切り落としたい厚板加工

 |
| **マルチ切断（Multi-Cut）** | 同一パスを複数回切断

 | 1回で貫通しない厚板の加工

 |

### リングカット（Ring Cut）

鋭角コーナーで方向転換する際の減速による過熱・溶融を防ぐため、角の外側に小さなループ軌跡を生成する機能。

#### リングカットパラメーター表

| パラメーター | 説明 | 推奨値 |
| --- | --- | --- |
| 最大角度（Max angle） | 適用するコーナーの最大角度（これより鋭角に適用）

 | 90°（鋭角コーナー対象）

 |
| 最小長さ（Min length） | 生成されるリングパスの最小長さ

 | 3mm

 |
| 延長長さ（Extend length） | コーナーを通り越す距離（リングサイズに直結）

 | 8mm（板厚に応じ調整）

 |
| レーザーOFF | リングパス通過中にレーザーを消灯

 | 通常はOFF（チェックなし）

 |
| 対象パス（Options） | Auto（自動） / Outer path / Inner path / Outer and Inner

 | 通常は「Auto」

 |

* **操作手順:** 図形選択 → Homeメニュー「リングカット」→ 設定入力 →「OK」。


* **削除:** Ring Cutダイアログ内「Clear path」、または「Clear」→「Clear Ring Cut」。



### カーフ補償（Seam Compensation）

レーザーの切断代（カーフ幅: 0.1〜0.5mm程度）による寸法縮小をオフセット補正する機能。

#### 補正の原則

* **外輪郭（製品外形）:** 外側にオフセット（拡大方向）


* **内輪郭（穴・くり抜き）:** 内側にオフセット（縮小方向）


* **補正量（片側）計算式:**
$$\text{補正幅} = \frac{\text{図面寸法} - \text{実測寸法}}{2}$$



*(例: 100mm正方形の実測が99.6mmの場合、補正幅は0.2mm)*


* **設定手順:** 図形選択 → Homeメニュー「補正」→ 補正幅・方向・コーナーフィレット有無を設定 →「OK」（描画ボード上に白い補正パスが表示）。


* **削除:** 図形選択 →「Clear」→「clear kerf compensation」、または補正ダイアログの「補正のクリア」。



### クーリングポイント（Cooling Point）

コーナー部にレーザーOFF・ガス噴射のみの一時停止ポイントを設け、過熱を防ぐ機能。（画面上は白い塗りつぶし円「●」で表示）。

#### 冷却遅延時間の目安表（F2 → グローバルパラメーター → Default Settings → Cooling delay）

| 材質 | 板厚 | 冷却遅延時間の目安 | 備考 |
| --- | --- | --- | --- |
| 鉄（軟鋼） | 〜3mm | 200〜500ms | 薄板は短めに設定

 |
| 鉄（軟鋼） | 4〜6mm | 500〜1000ms | 板厚に応じて設定

 |
| 鉄（軟鋼） | 6mm以上 | 1000〜2000ms | 熱が蓄積しやすいため十分冷却

 |
| ステンレス | 〜3mm | 500〜1000ms | 熱伝導が低く熱が逃げにくいため

 |
| ステンレス | 4mm以上 | 1000〜3000ms | テストカットにて最適化

 |
| アルミ | 〜3mm | 300〜800ms | 熱伝導が高いため比較的短めで可

 |

* **手動設定:** Homeメニュー「冷却点」をONにし、図形上の角をクリック（`ESC` で終了）。


* **自動設定:** Homeメニュー「冷却点」ドロップダウン →「自動冷却点」→ 位置（鋭角コーナー/リードライン）および適用上限角度（推奨60°以下）を指定して「OK」。


* **削除:** 個別は `Shift` + クリック。一括は「冷却点」ドロップダウン →「冷却点のクリア」。



### 多段ピアッシング（穴開け設定）

厚板（6mm以上）切断時のスパッタ飛散やノズル・レンズ保護のため、穿孔を多段階に分ける設定。

* **設定画面:** `F2`（レイヤー設定）→ 対象レイヤー →「穴開け」タブ。



#### 多段ピアッシングパラメーター表

| パラメーター | 説明 | 設定傾向 |
| --- | --- | --- |
| ピーク出力（%） | 各段階のレーザー出力

 | 段階に応じて徐々に上げる（例: 40% → 60% → 80% → 100%）

 |
| パルス周波数（Hz） | 各段階のパルス発振周波数

 | 初期は高周波、貫通直前に向けて周波数を下げる

 |
| ピアス時間（ms） | 各段階の照射持続時間

 | 板厚に応じて長く設定（合計時間＝板厚×係数）

 |
| ガス種 | 段階ごとのアシストガス

 | 鉄: O2、SUS: N2 または Air

 |
| ガス圧力（bar） | 段階ごとのガス圧力

 | 飛散防止のため切断時より低めに設定

 |
| ノズル高さ | 段階ごとのノズル追従高さ

 | スパッタ回避のため切断時（通常1mm）より高く（3〜5mm）設定

 |

## 7. ネスティング（部品配置最適化）と配列

画面上部「ネスト」ドロップダウンから「ネスト」画面を起動。

### ネスティング手順

1. **パーツ登録（パーツライブラリ）:** 図形右クリック →「パーツライブラリに追加」（または左側「パーツ」タブで右クリック → パーツ読み込み）。最大50種類まで、数量（必要枚数）を設定。


2. **プレート設定（プレートライブラリ）:** 左側「プレート」タブで右クリック →「プレートを追加」。板材の幅・長さ・材質・厚さ・枚数を入力（最大20枚、本機最大加工サイズ: 1500×1000mm）。


3. **パラメーター設定:**
* **パーツ間隔（Part gap）:** 2mm以上（3mm厚以上は3mm以上推奨）。


* **余白（Plate margin）:** 2mm以上推奨。


* **回転角度（Rotation Angle）:** 90°推奨（方向制約がある材料は0°）。


* **ネスト方向:** 下から上（推奨）。


* **自動共通辺（Auto Co-edge）:** 共有辺を1本の切断線に集約する場合にON。


* **ネスト戦略:** 配列（Array）固定。




4. **実行・確認:** 「ネスト」を実行し、左サイドバーの「ネスト結果」で各プレートの歩留まりを確認。



### 簡易配列（Array）機能の操作

| 配列機能 | 概要 | 操作手順 |
| --- | --- | --- |
| **矩形配列** | 行・列数と間隔を指定して格子状に配置

 | パーツ選択 →「配列」→ 行数・列数・間隔（オフセット/間隔）を指定し「OK」。

 |
| **動的配列** | カーソルドラッグで視覚的に配置

 | パーツ選択 →「ダイナミック配列」→ 行・列間隔を入力 → 描画ボード上をドラッグして確定。

 |
| **円形配列** | 円周上にパーツを配置

 | パーツ選択 →「円形配列」→ パラメーター入力 → 配置中心をクリック。

 |
| **フィル（Fill）** | 板材サイズ内に最大個数を自動敷き詰め

 | 事前に板材パラメーター設定後、パーツ選択 →「フィル」→「OK」。

 |

## 8. 端検出（Find Edge）

テーブル上に置かれた板材の端を計測し、傾きと原点を自動補正する機能。

*(前提条件: 必ず事前に「原点復帰」を済ませておくこと。板の傾きが10°を超える場合は検出不可)*。

### 5種類の検出方式

| 方式 | 傾き補正 | 位置補正 | 主な用途・特徴 |
| --- | --- | --- | --- |
| **① 静電容量端検出** | ○ | ○ | **通常加工全般で推奨。** BCS100センサーで自動計測（3点クイック / 6点回避スラット）。

 |
| **② 2点端検出** | ○（1辺） | △ | 上・下・左・右のいずれか指定した1辺のみの傾きを補正。

 |
| **③ 1-point FindEdge** | × | ○ | 1辺の端位置のみを把握し、原点位置を合わせる（傾き補正なし）。

 |
| **④ 円の中心** | × | ○（中心） | 円形板材や円形穴の中心を原点として割り出す。

 |
| **⑤ 手動端検出** | ○ | ○ | センサー不使用。ヘッドを手動でP1・P2に合わせて登録。

 |

### 静電容量端検出の操作手順

1. `CNCタブ` →「端検出」→「静電容量端検出」を開く。


2. 「シートの寸法を指定」に実際の板材サイズ（X・Y）と余白を入力（※実寸より大きい値を入力すると機械の歯にヘッドが衝突する危険あり）。


3. 戦略から「3点クイック端検出」（通常）または「6点回避スラット」（高精度・薄板）を選択。


4. スタート点（「現在の位置から開始」を推奨）を選択し、ヘッドを板の内側に手動移動しておく。


5. 「保存」をクリック後、「3点クイック端検出」をクリックして実行。


6. 検出完了後、右上に表示された角度・位置を確認し、「枠線（Frame）」で動作範囲を確認。

## 9. 加工順序・原点設定・テスト

### 原点・加工始点設定

* **加工始点（Start Point）:** 切断開始位置の痕を目立たない場所へ移す際に「加工始点」をクリックして任意位置を指定。


* **加工原点（Zero Ref）:** プログラム基準点。通常は「左下」、円切り抜きセンター基準は「中心」を指定。



### 加工順序（並び替え / Sort）

板材のズレや熱変形を防ぐため、**「文字（微細形状） → 小穴 → 内側輪郭 → 外周」** の順序で切断する。

* **自動ソート手順:** 「並び替え（Sort）」→「スマート並び替え」を選択。


* **手動優先度調整:**
* 外周部分を選択 → `Move Last`（最後へ移動）


* 穴・文字部分を選択 → `Move Front`（最前へ移動）




* **ソートモード:**
* **スマート並び替え:** 効率と熱バランスの最適化（推奨）。


* **グリッドパターン:** 均一なパーツ群を規則的にソート。


* **手動ソート:** 【表示タブ → 並び替え → START SORT → 完了しました】で個別指定。


* **最短パス:** ヘッド移動距離を最小化（※材料ズレのリスクあり）。





### 事前チェック方法

* **シミュレート（PC画面）:** 画面上で切断順序・ヘッドの空走パスを動画確認（機械は動作しない）。


* **ドライカット（Dry Run）:** レーザーをOFFにした状態で、ヘッドが実パス通りに切断動作を行う実機トレース確認。


* **枠線（フレーム / Frame）:** 【最低限必須】加工図形全体の最大外形枠に沿ってヘッドが四角形を描くように動く。材料からはみ出していないか即座に確認可能。

## 10. 加工実行とリモートコントローラー

### 加工実行手順

1. 最終確認（稼働域の障害物なし、切り屑受け設置、安全カバー閉止、保護メガネ着用、枠線確認）。


2. 画面の **「シャッター（Shutter）」** ボタン（またはリモコン⑤）を押す。


3. ガイドレーザー（赤ポインター）が**消灯**したことを確認（消灯＝発振スタンバイOK）。


4. **「スタート（Start）」** ボタン（またはリモコン①）をクリックして切断を開始。



### リモートコントローラーのボタン配置と機能

| 番号 | ボタン名 | 機能説明 | 備考 |
| --- | --- | --- | --- |
| **①** | **スタート** | 加工を開始する。

 | PC画面の「スタート」と同等。

 |
| **②** | **ポーズ** | 加工を一時停止する。

 | 停止に若干のタイムラグあり。再開可能。

 |
| **③** | **ドライカット** | レーザーOFFで実軌跡を空移動トレース。

 | 動作確認用。

 |
| **④** | **ストップ** | 加工を即時中断中止する。

 | **途中再開不可**（原点復帰後やり直し）。

 |
| **⑤** | **シャッター** | 発振スタンバイ。赤ポインターを消灯させる。

 | 切断開始前に必ず押す。

 |
| **⑥** | **レーザー** | テスト発振ボタン。

 | ⚠ 危険なため、通常は使用不可。

 |
| **⑦** | **フレーム（枠線）** | 切断全域の外枠をヘッドが移動。

 | 材料枠外れ防止のため切断前に必須。

 |
| **⑧** | **ファスト** | 早送り移動。カーソルキーと同時押し。

 | 大まかな位置合わせ。

 |
| **⑨** | **ステップ** | 微調整移動。ステップ＋カーソルキー押下。

 | 規定値（1mm等）ずつ移動。

 |
| **⑩** | **カーソル** | 上下左右にヘッドをジョグ移動。

 | ⑧・⑨と併用。

 |

* ※予期せぬ切断中断（アラーム等）が起きた場合、図形や設定を変更していなければ、画面右側の「Pt LOC（ブレークポイントへ移動）」→「Pt CONT（ブレークポイントから再開）」で継続可能。

## 11. 日常・定期メンテナンス

### 日常点検（毎使用前）

* 加工ヘッドの保護レンズの汚れ・傷の点検。


* ノズルの詰まり・歪み・スラグ付着の点検。


* 各種配線ケーブル・ガスホースの破損チェック。


* チラー冷却水の水位および水温（20℃以上32℃未満）の確認。


* 本機底面の切り屑受けトレーの清掃・堆積物の除去。



### 定期点検・清掃周期表

| 頻度 | 点検・作業項目 |
| --- | --- |
| **毎日** | 日常点検項目を全数実施。

 |
| **週次** | 加工ヘッド光学部品（保護レンズ等）の清掃または交換。エアーコンプレッサーの水抜き。

 |
| **月次** | チラー冷却装置の吸気フィルター清掃（エアブロー）。ガイドレールへの注油・オイル量確認。

 |
| **半期〜年次** | レーザー発振器の専門点検。電気系統・制御盤の点検。各駆動部の摩耗・緩みの点検。

 |

## 12. トラブルシューティング（エラー・不具合対処）

### 加工トラブルと対処一覧

| 現象・アラーム | 想定原因 | 対処方法 |
| --- | --- | --- |
| **レーザーが出力されない**

 | 発振器電源キーがOFF

 | ③発振器電源キーおよび起動手順（①→②→③）を確認。

 |
|  | チラー水温の規定外

 | 水温が20℃〜32℃の範囲に安定するまで待機。

 |
|  | シャッターが閉塞中

 | 画面またはリモコンの「シャッター」を押し、赤ポインターを消灯させる。

 |
|  | 電圧降下

 | 加工中電圧が360V以上あるか確認（受電盤等の点検）。

 |
|  | ソフト上でアラーム作動

 | CypCutEのアラームウィンドウを確認し警告要因を排除。

 |
| **切断品質の悪化（バリ・溶損・不貫通・跳ね返り）**

 | 保護レンズの汚れ・傷

 | レンズをアルコール清掃、または新品へ交換。

 |
|  | 切断条件の不一致

 | 焦点位置（フォーカス）、加工速度、出力を端材でテスト調整。

 |
|  | アシストガス圧力不足

 | 配管圧力が1.5MPa以上あるか確認。ボンベ残量確認。

 |
|  | ノズルの消耗・中心ズレ

 | ノズルを清掃または交換。ノズルセンター出しを実施。

 |
|  | 表面処理材の影響

 | 塗装やメッキがある場合、条件変更または無垢材での加工を検討。

 |
| **切断寸法の狂い・精度不良**

 | 母材のズレ・浮き

 | 板のクランプ固定を見直す、または厚板に変更。

 |
|  | 切断順序の誤り

 | 外周より先に内側形状を切るよう「スマート並び替え」を再実行。

 |
|  | 切断送り速度が速すぎる

 | コーナー部や微細部で減速させるか、全体の加工速度を下げる。

 |
| **リード線の干渉・開始点溶融**

 | リード長すぎ・進入角不良

 | 「Check leadline」を実行。リードイン長さ・角度を見直す。

 |
|  | ピアススパッタ・助走不足

 | リードイン長さを伸ばす。多段ピアッシング条件を見直す。

 |
|  | 輪郭が開いている

 | 「Join Line」で閉じた輪郭に修復してからリード線を再設定。

 |
| **リングカット不具合**

 | 適用角度の設定外

 | Max angleの設定値を広げる（例: 60°→90°）。

 |
|  | 隣接パーツとの干渉

 | Extend lengthを短縮（3〜5mm目安）またはパーツ間隔を広げる。

 |
| **クーリングポイント不具合**

 | 冷却不足で焼けが残る

 | Cooling delay時間を延ばす（例: 500ms→1000ms）。

 |
|  | 加工時間が著しく延びる

 | 不要箇所のポイント削除、または遅延時間を短縮。

 |
|  | リード上の点が消えない

 | リードラインごと削除してから再設定。

 |
| **カーフ補償不具合**

 | 補正後に図面と逆寸法化

 | 内外輪郭が誤認識されているため、内枠/外枠オプションを再設定。

 |
|  | 角に異常な飛び出しが発生

 | コーナー処理の「Corner fillet」をONにする。

 |
| **端検出エラー**

 | 検出途中でヘッド停止

 | 入力したシート寸法が実寸より大きいため、小さめに修正。

 |
|  | 検出角度が毎回狂う

 | 板材端面の汚れ・反りを除去。傾きが10°以内に手動で修正。

 |
|  | 置き直した後にズレる

 | 「端検出結果をクリア」を必ず押してから再検出を実行。

 |

### 異音・異臭・緊急停止後の復旧

1. 機械部品の摩耗、電気異常、光学部品の過熱等の場合は**直ちに「緊急停止ボタン」を押下**。


2. 危険・障害要因が完全に排除されたことを目視確認。


3. 緊急停止ボタンを**右に回して**ロックを解除。


4. CypCutE画面のアラームウィンドウを確認し、エラーを解除。


5. 画面左下より「原点復帰」を実行。


6. ヘッド・材料の状態を点検後、運転を再開。
